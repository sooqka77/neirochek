# НейроЧек

Белый GEO-чекер и набор инструментов видимости локального офлайн-бизнеса в ИИ: **Яндекс с Алисой (Нейро), ChatGPT, Perplexity, GigaChat и DeepSeek**.

## Что умеет MVP
- **Матрица живых запросов (5 бесплатно + 5 PRO-тест):** 1-клик запуск реального районного, сценарного, сравнительного и бренд-запроса в Алисе, ChatGPT, Perplexity, GigaChat и DeepSeek.
- **Анализатор реальных ответов ИИ:** определяет факт упоминания бренда (с учётом падежей и синонимов), позицию в рейтинге, галлюцинации / информационный вакуум, список конкурентов и домены цитирования.
- **Опциональный автопилот через API:** можно подключить свой ключ OpenRouter (хранится только локально в браузере) и прогнать запросы одной кнопкой через Perplexity Sonar / GPT-4o Online / Gemini Online.
- **Диагностика ИИ-готовности по 14 белым факторам (0–100 баллов).**
- **PRO (открыт бесплатно на время теста, с превью paywall):**
  - Нишевая карта источников цитирования РФ (9 офлайн-ниш) со ссылками.
  - Генератор валидного `Schema.org` (`LocalBusiness` / нишевый `@type` + `sameAs`).
  - Генератор файла `/llms.txt` и правил `/robots.txt` для ИИ-ботов.
  - Редактируемый **GEO-FAQ** с готовым HTML + `FAQPage` JSON-LD.
  - Словарь смыслов для живых отзывов и трекер динамики замеров.

## Архитектура
Полностью статическое приложение без внешних JS-зависимостей — работает на GitHub Pages и стабильно открывается в РФ.
